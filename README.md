## ✅ 已实现功能

### 🚀 性能

- **启动速度** — 冷启动快，打开即用
- **内存占用小** — 多标签浏览时内存占用更低
- **网页性能** — [Speedometer](https://browserbench.org/Speedometer3.1/) 跑分较高（因硬件而异，仅供参考）

### 🔄 账号与数据同步

- **双账号登录** — Turbo / Google
- **数据同步** — Turbo 增量同步书签、密码（含 Passkey）、设置、扩展；书签 / 密码可单独开关；新安装默认关密码同步；Google 账号走 Google 同步

### 📦 数据迁移与导入

- **自 Chrome / Edge 迁入** — 书签、密码、自动填充、扩展
- **自 Safari 迁入（macOS）** — 书签；必要时会引导开启系统权限

### 🛡️ 应用商店与扩展

- **Chrome / Edge 双商店** — 菜单与扩展管理页均可进入
- **Crx搜搜** — 扩展页侧栏一键安装 `.crx`
- **内置翻译** — 右键菜单 / 地址栏可整页翻译
- **推荐扩展** — AdGuard、沉浸式翻译（官网 `.crx` 一键安装，非预装）

### 🖱️ 鼠标手势与老板键

- **老板键** — 默认 `Ctrl+Q`；可自定义；可关隐藏静音 / 恢复前台
- **鼠标手势** — 右键拖动触发，路径可视化，动作可自定义
- **超级拖拽** — 链接 / 图片 / 文字按方向打开、搜索或复制

### ✂️ 界面与效率

| 能力 | 说明 |
| --- | --- |
| **一键换肤 / 分屏** | 标题栏换肤；工具栏左右或上下分屏 |
| **截图** | 全屏 / 网页导出（PNG / JPEG / PDF）；Windows 长截图；`Ctrl/Cmd+Shift+X` 区域截图 |
| **下载增强** | 多线程加速；可识别 10 款下载工具；页内确认框；Alt 快速存图 |
| **沉浸模式** | 自动隐藏标签栏与工具栏；可下次自动进入；垂直标签亦可进入；`Ctrl/Cmd+F11` |
| **新标签页** | 我的网址 / 最常访问；可调外观与独立搜索引擎 |
| **书签** | 书签菜单、多列、自动隐藏 / 仅图标、单击新标签打开等 |
| **工具栏** | 可定制；恢复网页、截图等入口 |
| **其它** | 系统主题、网络代理、自定义缓存目录、退出时清理所选数据 |

### 🏷️ 标签与地址栏

- **垂直标签** — 左右侧布局、通栏 / 工具栏以下样式；悬停展开；可始终显示滚动条、书签菜单按钮；可与沉浸模式同用
- **标签页** — 双击 / 右键关闭、悬停激活、滚轮切页、多列标签搜索、误关恢复、淡化闲置、标签静音等
- **小号标签** — 普通窗口内的持久身份；关标签不销毁登录；`Ctrl+M` / `⌃⌘M`
- **粘贴即打开** — 右键「+」读取剪贴板打开链接或搜索
- **地址栏** — 二维码、复制网址 / 标题+网址、可固定查找；可开关完整网址与若干入口
- **精细缩放 / macOS 刷新** — `Shift` 5% 步进；macOS 支持 `F5` / 强制刷新

### ⬆️ 升级与安装

- **内核** — 持续跟进 Chromium 主线；版本见 [下载安装](https://tbrowser.cn/zh/guide/download.html)
- **更新** — 设置页检查；后台自动检查
- **安装** — Windows / macOS；另提供 [Windows 绿色版](https://tbrowser.cn/zh/guide/download.html#portable-zip)
